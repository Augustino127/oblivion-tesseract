## 🎭 Concept Narratif

Cette plateforme raconte l'histoire des **patterns universels** qui se répètent à toutes les échelles de l'univers, du quantique au cosmique. Les mathématiques sont le langage qui connecte tout.

## 📚 LES CHAPITRES

### Chapitre 1 : Le Pattern Universel 🌀
**Scène** : Spirale de Fibonacci / Spirale d'Or

**Narration** :
> "Tout commence par un simple ratio : le nombre d'or φ = 1.618...
> De ce nombre naît une spirale qui se retrouve partout dans la nature."

**États visualisés** :
1. Rectangle d'Or (proportions parfaites)
2. Carrés de Fibonacci (1, 1, 2, 3, 5, 8, 13...)
3. Spirale 2D logarithmique
4. Spirale 3D (coquillage nautile)

**Message** : Les mathématiques pures génèrent des formes naturelles

**Exemples dans la nature** :
- Coquilles d'escargot
- Tournesols
- Ananas
- Oreille humaine
- Ouragans

### Chapitre 2 : Les Dimensions Cachées 📐
**Scène** : Tesseract (Hypercube 4D)

**Narration** :
> "Au-delà de notre perception, des dimensions supérieures existent.
> Le tesseract est une fenêtre vers la 4ème dimension spatiale."

**États visualisés** :
1. Patron 3D (8 cubes dépliés)
2. Pliage 4D progressif
3. Hypercube complet
4. Projections multiples (orthographique, stéréographique)

**Message** : Notre réalité 3D n'est qu'une projection d'une géométrie plus vaste

**Concepts physiques** :
- Dimensions compactifiées (théorie des cordes)
- Espace-temps 4D (relativité)
- Géométries non-euclidiennes

### Chapitre 3 : La Courbure de l'Espace-Temps ⚫
**Scène** : Trou Noir

**Narration** :
> "La gravité n'est pas une force, mais la géométrie de l'univers.
> Les trous noirs sont des régions où l'espace-temps est infiniment courbé."

**États visualisés** :
1. Espace euclidien plat (géométrie normale)
2. Effondrement gravitationnel (formation)
3. Horizon des événements
4. Trou noir avec disque d'accrétion

**Message** : La masse déforme l'espace-temps comme une boule sur un drap

**Phénomènes** :
- Métrique de Schwarzschild
- Rotation (métrique de Kerr)
- Frame-dragging (entraînement de l'espace)
- Lentille gravitationnelle

## 🔬 CONCEPTS SCIENTIFIQUES SOUS-JACENTS

### Mathématiques
- Suite de Fibonacci : F(n) = F(n-1) + F(n-2)
- Nombre d'or : φ = (1 + √5) / 2 ≈ 1.618
- Spirale logarithmique : r = a·e^(bθ)

### Physique
- Métrique de Schwarzschild : ds² = -(1-2M/r)dt² + (1-2M/r)⁻¹dr² + r²dΩ²
- Rotation képlérienne : v ∝ 1/√r
- Conservation du moment angulaire : L = r × p

### Géométrie
- Projection stéréographique 4D→3D
- Courbure de Riemann
- Variétés différentielles
